# Hollow Pass

A complete, playable 3D tower defense game in a single HTML file. Three.js, no build step.

Hold the mountain road against 20 waves of raiders with Arrow, Cannon and Frost towers. Upgrade, sell, stack waves early for bonus gold, survive the warlords on waves 10, 15 and 20.

Play it: https://ryx168.github.io/ember-ridge-d643/

Keys: 1 / 2 / 3 pick a tower, U upgrade, X sell, Esc cancel, Space sends the next wave. Mouse wheel zooms.

Deployed to GitHub Pages by the workflow in `.github/workflows/pages.yml` on every push to `main`.
